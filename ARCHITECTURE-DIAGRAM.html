MailFlow Architecture

Mobile-first PWA: Gmail inbox voice processing with persistent session bookmarks

Frontend Stack

  • Next.js 16 (App Router, Turbopack)
  • React 19 with custom hooks
  • Tailwind CSS v4 styling
  • Service Worker (offline support)
  • PCM Worklet (audio capture)

Backend Stack

  • Next.js API Routes (Node.js)
  • Auth.js v5 (NextAuth)
  • Domain Layer (lib/)
  • Edge Middleware (proxy.ts)
  • Token encryption (AES-256-GCM)

Data & External

  • MongoDB (user data, sessions)
  • Session bookmarks (progress)
  • Gmail API (googleapis)
  • OpenAI API (TTS, STT, cleanup)
  • Google OAuth (authentication)
