# Sidebar & Navigation UI Issues

## Issue 10: Sidebar Modernization

The sidebar needs a modern refresh and better UX patterns.

### Reference Design
See the example here: https://ui.shadcn.com/docs/components/base/sidebar

### Required Changes

1. **Padding & Spacing**
   - Increase padding on sidebar items to feel more spacious and modern

2. **Collapse State Icon Alignment**
   - When the sidebar is collapsed, the icons aren't horizontally centered
   - Fix icon centering in collapsed mode

3. **Profile Menu at Bottom**
   - Move the profile Avatar and username to the bottom of the sidebar
   - Make it a clickable menu button that shows:
     - Settings
     - Account-level options
     - Sign out button
   - This is a standard modern UX pattern
