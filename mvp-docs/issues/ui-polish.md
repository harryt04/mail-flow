## Issue 11: Button Clarity & Settings

Skip and snooze sound like they should do the same thing, but they probably don't. This creates confusion.

### Problems
- No clear indication of what each button does
- Ambiguity between "Skip" and "Snooze" functionality
- The snooze action is undefined and confusing

### Required Changes

1. **Add Tooltips**
   - Add tooltips wherever close/action buttons exist
   - Clearly communicate what clicking on a button actually means

2. **Snooze Settings**
   - Create a setting in the settings page so users can define what "Snooze" means
   - Examples: hide for 1 day, 1 week, archive, move to folder, etc.

3. **Consider Consolidation**
   - If snooze and skip end up being too similar, consider consolidating them into a single action
